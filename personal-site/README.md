# 摄影与设计作品集

基于 HTML5 UP 的 Massively 模板制作的中文摄影与设计作品集。保留原模板的封面、作品网格、移动端菜单与滚动效果，新增个人介绍、摄影与设计作品分区，以及可展开的作品介绍。无需安装依赖，无需构建。

## 本地查看

双击 index.html 即可在浏览器查看。所有展示所需样式、脚本和图片均在项目中，不依赖在线字体。

## 替换个人内容

打开 index.html，搜索“你的名字”“待填写”，替换姓名、介绍和作品内容。作品图片在 images 文件夹中，对应 pic01.jpg 到 pic05.jpg；可以替换同名图片，也可以修改 HTML 中的图片路径与 alt 描述。

网站为纯展示用途，不包含联系方式、商业合作入口或联系表单。

自定义样式集中在 assets/css/personal.css。generic.html 与 elements.html 是原模板参考页，不属于个人站导航，可留作编辑参考。

## 后续上传 GitHub

将本文件夹内部的文件与 assets、images 文件夹一并上传到仓库根目录，让 index.html 位于根目录。无需上传原压缩包。

本次仅准备本地源码，没有创建远程仓库或上线。所有站内资源采用相对路径，可用于 GitHub 仓库子路径。若以后决定公开网站，再单独配置 GitHub Pages 即可。

## 来源和署名

模板：Massively by HTML5 UP（https://html5up.net），作者 @ajlkn。原始说明见 README.txt，许可见 LICENSE.txt。页面保留模板署名。

本项目在原模板基础上修改了中文内容、个人主页结构、字体回退、无障碍细节与作品介绍。模板图片目前作为占位使用，个人信息和作品均待你填入真实资料。
